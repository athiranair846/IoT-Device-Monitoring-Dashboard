# IoT-Device-Monitoring-Dashboard
Developed an IoT monitoring platform for collecting and visualizing sensor data from ESP32 devices. Built REST APIs for data transmission and storage, implemented dashboard analytics, and enabled real-time monitoring of environmental parameters.

## Features
- Real-time sensor monitoring
- Device status tracking
- Alert generation
- Historical data visualization

## Technologies
- IoT Concepts
- REST APIs
- Database Systems
- Data Visualization

## Future Scope
- ASP.NET Core API
- Angular Dashboard
- Cloud Deployment
